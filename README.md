# 跟唱音高線

貼上 YouTube 連結，跟著唱；播放器下方會畫出你自己聲音的即時音高線與目前的音名。

自己用的小工具：不評分、沒有歌詞、沒有歌庫、不用登入。

## 怎麼用

1. 用桌機的 Chrome 開啟網頁（要用 https 網址或下面的本機預覽，直接雙擊 `index.html` 不行）。
2. **戴上耳機。** 否則喇叭播出的歌聲會被麥克風當成你的聲音。
3. 貼上 YouTube 影片網址（`youtube.com/watch?v=…`、`youtu.be/…`、`youtube.com/shorts/…`、`youtube.com/embed/…`），想的話填上歌名，按「載入」。網址裡的其他參數（從第幾秒開始、播放清單等）會被忽略。
4. 按「開啟麥克風」。瀏覽器會問是否允許使用麥克風；回答之後影片開始播放，允許的話下方出現音高線。再按一次是「關閉麥克風」。
5. 唱完貼下一個連結即可。唱過的歌會列在「最近唱過」（最多 20 首，顯示你填的歌名，沒填就顯示影片代碼），可以按「清空」。

也可以不貼連結：頁面上的「歌單」列出預設的歌，點一下就載入。歌單取自 KKBOX 風雲榜台灣區單曲週榜（2026-11-19 當週）的部分歌曲，影片可能因上傳者設定而無法播放。

如果拒絕了麥克風（或電腦沒有麥克風），影片照常播放，只是沒有音高線。要重新允許：點網址列左邊的圖示 → 網站設定 → 麥克風 → 允許，再重新整理。

## 限制（請先看）

- **不評分。** 網頁讀不到 YouTube 影片的聲音，不知道這首歌該唱什麼音，所以只畫你自己的音高。
- **要戴耳機。** 見上。
- **有些影片不能播。** 影片擁有者可以禁止嵌入（很多官方 MV 是這樣），這時會顯示「這支影片不允許嵌入，請換一支」。
- **只在桌機 Chrome 的自動化測試環境驗過**（無頭 Chromium、1280×800、以測試音當作麥克風輸入）。真實麥克風、真實歌聲、手機、Safari、Firefox 都沒有驗過。
- 音高偵測針對單一人聲，支援 80–1000 Hz。氣音、環境吵雜或多人同時唱時，線會斷掉或亂跳。
- 靜音門檻：一段聲音的均方根音量低於 0.01（滿刻度為 1，約 −40 dBFS）就當成沒有聲音、不畫線。比這個大的環境噪音若剛好有音高，會被畫出來。
- 音高線比你的聲音晚一點點出現（分析用的聲音片段約 0.04 秒，加上畫面更新）；麥克風與藍牙耳機本身的延遲無法由網頁控制。
- 按「開啟麥克風」後若影片沒有自動播放，直接點一下播放器即可。

## 隱私

- 麥克風的聲音只在你的瀏覽器裡即時分析，分析完就丟掉：不錄音、不儲存、不上傳。
- 這個網頁沒有伺服器，不收集任何資料。「最近唱過」只存在你這個瀏覽器的 localStorage（鍵名 `singalong-pitchline.recent.v1`，內容是影片代碼與你自己填的歌名）。
- 唯一的第三方資源是 YouTube 的官方播放器（按「載入」後才會連到 YouTube）。播放影片時適用 YouTube 自己的條款與隱私權政策。
- 這個網頁自己允許的外部主機只有一個：`www.youtube.com`（播放器的腳本 `/iframe_api` 與它載入的播放器程式，以及播放器的 iframe）。頁面的內容安全政策把腳本與框架限制在本站與這個主機，頁面自己的其他對外連線（fetch 等）一律不允許。播放器的 iframe 內部還會連哪些主機由 YouTube 決定。
- 不向 YouTube 查詢影片標題。

## 檔案

| 路徑 | 內容 |
|---|---|
| `docs/` | 網頁本身（GitHub Pages 從這個資料夾發布） |
| `docs/js/pitch.js` | 音高偵測（YIN 演算法）與音名換算，純函式 |
| `docs/js/link.js` | YouTube 連結解析、歌單資料檢查，純函式 |
| `docs/js/songs.js` | 歌單資料。加歌只改這個檔 |
| `docs/js/app.js` | 畫面、播放器、麥克風 |
| `harness/`、`tools/` | 開發用：測試頁、本機預覽伺服器、自測腳本。不屬於網頁 |

## 加歌到歌單

只需要改 `docs/js/songs.js`，在 `K.songs = [` 與 `];` 之間每首歌加一行：

```js
    { title: "歌名", artist: "歌手", id: "影片代碼" },
```

- 影片代碼是 YouTube 網址裡 `watch?v=` 後面（或 `youtu.be/` 後面）的 11 個字元。
- 歌手可以留空（`""`）；歌名與影片代碼不能空。
- 格式不對的那一行會被略過，其他歌照常顯示；整個檔案寫壞了就當成空歌單，網頁其他功能不受影響。
- 歌單裡的影片若禁止嵌入，點了會顯示「這支影片不允許嵌入，請換一支」。加歌前先在網頁上貼連結試一次比較保險。

## 本機預覽與測試（開發用）

需要 Python 3，不需安裝任何套件：

```bash
python3 -m tools.serve          # 開 http://127.0.0.1:8770/docs/
```

自測腳本另外需要 Playwright 與它的無頭 Chromium：

```bash
python3 -m tools.selftest            # 不連外：音高偵測以合成波形驗證；畫面以替身播放器與假麥克風驗證
python3 -m tools.selftest --youtube  # 另外載入一次真正的 YouTube 播放器
```
